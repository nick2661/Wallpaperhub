# WallpaperHub - User Guide

Welcome to WallpaperHub! This guide will help you get the most out of your wallpaper browsing and downloading experience.

## 🚀 Getting Started

### First Visit

1. **Open the Website**
   - Navigate to the website URL in your browser
   - The homepage will load with featured wallpapers

2. **Choose Your Theme**
   - Click the moon/sun icon in the top-right corner
   - Toggle between light and dark mode
   - Your preference is automatically saved

## 🔍 Finding Wallpapers

### Method 1: Browse by Category

1. **View Categories**
   - Scroll down to the "Browse by Category" section
   - You'll see 8 categories with icons:
     - 🌲 Nature
     - 🎨 Abstract
     - 💻 Technology
     - ⚪ Minimalist
     - 🌙 Dark Mode
     - 🐉 Anime
     - 🚗 Cars
     - 🚀 Space

2. **Select a Category**
   - Click on any category card
   - The page automatically scrolls to the gallery
   - Only wallpapers from that category are shown

### Method 2: Use Filters

1. **Find the Filter Bar**
   - Located just above the wallpaper gallery
   - Shows buttons for each category

2. **Apply a Filter**
   - Click any filter button
   - The gallery updates instantly
   - Click "All" to see everything again

### Method 3: Search

1. **Use the Search Bar**
   - Located in the hero section at the top
   - Type keywords like "mountain", "ocean", "neon"

2. **Auto-suggestions**
   - As you type, suggestions appear below
   - Click a suggestion to search instantly
   - Press Enter to search manually

3. **Keyboard Shortcut**
   - Press `Ctrl + K` (Windows) or `Cmd + K` (Mac)
   - Search bar is instantly focused

## 📥 Downloading Wallpapers

### Quick Download

1. **Hover Over a Wallpaper**
   - Move your mouse over any wallpaper card
   - Action buttons appear in the top-right

2. **Click Download Icon**
   - Click the download icon (⬇️)
   - Wallpaper downloads immediately in 4K resolution

### Detailed Download

1. **Open Wallpaper Details**
   - Click anywhere on a wallpaper card
   - A modal window opens with full details

2. **Choose Resolution**
   - Select from 4 options:
     - HD (1920x1080) - Standard displays
     - 2K (2560x1440) - High-quality displays
     - 4K (3840x2160) - Ultra HD displays
     - 8K (7680x4320) - Maximum quality

3. **Choose Device Type**
   - Select your device:
     - 🤖 Android - For Android phones/tablets
     - 🪟 Windows - For Windows PCs
     - 🍎 iOS - For iPhones/iPads
     - 🖥️ Desktop - For any desktop computer

4. **Download**
   - Click the "Download Wallpaper" button
   - File downloads to your default download folder
   - A success notification appears

## 💝 Managing Favorites

### Adding Favorites

1. **From Gallery**
   - Hover over a wallpaper
   - Click the heart icon (♡)
   - Heart fills in (♥) to confirm

2. **From Details Modal**
   - Open wallpaper details
   - Click "Add to Favorites" button
   - Button changes to show it's favorited

### Removing Favorites

1. **Click the Heart Again**
   - Click the filled heart icon
   - Heart becomes outlined again
   - Wallpaper removed from favorites

### Viewing Favorites

- Your favorites are saved in your browser
- They persist even after closing the browser
- Access them anytime you return to the site

### Setting Wallpapers

**Windows:**
1. Download wallpaper
2. Right-click on desktop
3. Select "Personalize"
4. Choose "Background"
5. Browse to downloaded image

**Mac:**
1. Download wallpaper
2. Open System Preferences
3. Click "Desktop & Screen Saver"
4. Click "+" to add image
5. Select downloaded wallpaper

**Android:**
1. Download wallpaper
2. Open Gallery/Photos
3. Select the image
4. Tap menu (⋮)
5. Select "Set as wallpaper"

**iOS:**
1. Download wallpaper
2. Open Photos app
3. Select the image
4. Tap share icon
5. Select "Use as Wallpaper"

## 🐛 Troubleshooting

### Common Issues

**Images Not Loading**
- Check internet connection
- Refresh the page
- Clear browser cache
- Try different browser

**Download Not Working**
- Check browser download settings

- Try different browser

**Search Not Working**
- Clear search field
- Try different keywords
- Refresh the page
- Check JavaScript is enabled

**Theme Not Saving**
- Enable cookies in browser
- Check localStorage is enabled
- Try different browser
- Clear browser data and retry

**Mobile Menu Not Opening**
- Refresh the page
- Check JavaScript is enabled
- Try different browser
- Update your browser
