# 🎉 Welcome to WallpaperHub!

## ⚡ Quick Start (30 Seconds)

1. **Open `index.html`** in your web browser
2. **Browse wallpapers** by category or search
3. **Click any wallpaper** to view details and download
4. **Toggle theme** with the moon/sun icon
5. **Open `admin.html`** to access the admin dashboard

**That's it! You're ready to go! 🚀**

### Common Issues

A: Clear browser cache and refresh

**Q: JavaScript errors?**

A: Ensure JavaScript is enabled

**Q: Theme not saving?**
A: Enable cookies in browser settings
